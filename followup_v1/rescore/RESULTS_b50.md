# 재채점 (50호출) — 2026-10-29 13:40 · 탐색적

**8호출에서 본 gnina 양성도 예산 효과였다.** 50호출에서 사라진다.
accept 층 128 사례 / 39 component / arm당 약 445 pose. 도킹은 다시 하지 않고 선택 함수만 바꿨다.

## 1. apo multi − single, top-1 (양수면 multi가 좋음)

| 선택 함수 | 8호출 | **50호출** |
|---|---:|---:|
| Vina | −0.084 [−0.389, +0.236] | −0.017 [−0.274, +0.275] |
| Vinardo | +0.057 [−0.172, +0.285] | −0.003 [−0.284, +0.268] |
| **gnina (CNNscore)** | **+0.541 [+0.131, +1.016]** | **+0.126 [−0.185, +0.489]** |

세 함수 모두 50호출에서 0이다. 8호출의 gnina 양성은 **재현되지 않았다.**

이유는 top-5 때와 같다. 8호출에서는 arm당 pose가 **72개**뿐이라 어떤 선택 함수든 oracle에 가깝게
동작한다(apo oracle 46/128 vs gnina 32/128 — 상한의 70%를 집어냈다). 50호출에서는 **445개**가 되어
진짜 선택 문제가 되고, 그때 gnina도 상한의 59%(68 중 43)로 내려온다.
**선택 함수의 이득은 후보 수가 적을 때 과대평가된다.**

## 3. 그러나 gnina가 훨씬 좋은 선택 함수인 것은 사실이다 (대비와 별개)

top-1 성공 절대값, 128 사례 중:

| 선택 함수 | apo single/multi | holo single/multi |
|---|---:|---:|
| Vina | 18 / 18 | 56 / 58 |
| Vinardo | 20 / 17 | 57 / 57 |
| **gnina** | **40 / 43** | **82 / 83** |
| (생성 상한, oracle) | 60 / 68 | — |

**apo에서 Vina는 상한 60 중 18개(30%)만 집어내고, gnina는 40개(67%)를 집어낸다.**
같은 pose 집합이고 선택만 바꾼 것이다. 즉 "선택이 병목"이라는 진단 자체는 옳았고,
gnina는 그 병목을 상당히 푼다.

**다만 그것이 multi − single 차이로는 나타나지 않는다.** gnina는 single의 좋은 pose도 같이
찾아내므로 양쪽이 함께 올라가고 차이는 0에 머문다(+0.126, CI가 0을 포함).

## 4. 해석에서 조심할 것

- **탐색적이다.** 확증 검정은 budget50의 P1/P2이고 이미 미달로 닫혔다(`budget50/RESULTS.md`).
  이 표의 어떤 칸도 확증으로 재지정하지 않는다.
- **gnina 학습 자료 누출.** 절대 성공률(40, 82)은 낙관적으로 편향됐다고 가정한다.
  §3의 "gnina가 더 좋은 선택 함수"는 **절대값 주장이므로 이 편향을 그대로 받는다.**
  대비(§1)는 같은 사례 안에서 arm만 다르므로 누출이 양쪽에 같이 들어가 편향되지 않는다.
- **sampling–scoring mismatch.** pose는 전부 Vina가 만들었다. 실험 C가 이 제약을 없앤 조건이다.
- **중복 제거 없음.** 여기 top-5는 `top5_raw`이며, pose table이 기하 구조를 들고 있지 않아
  거리 기반 중복 제거를 할 수 없다. budget50의 중복 제거 top-5와 직접 비교하지 않는다.

아니라 거의 oracle 측정이었다고 보는 것이 맞다.**
